## 评论与行内注释

- 阅读文章、评论和注释不需要登录

- 评论使用带 `discussion` 标签的 GitHub Issue
- 行内注释使用带 `annotation` 标签的 GitHub Issue
- 浏览器通过 GitHub 公共 API 读取公开内容，网页中不保存 Token 或密钥
